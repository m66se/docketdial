DocketDial drafts editable time entries by client and matter from the work records you provide or authorize.

## Downloads

- **DocketDial.md** is the single-file import for Microsoft 365 Copilot Cowork.
- **docketdial.zip** is ready to upload to Claude. Codex users can extract its docketdial folder into their skills directory.

## In this release

- The Copilot import is generated from the shared skill and its Microsoft 365 instructions. CI checks that the published Markdown matches its sources.
- The setup guide covers Claude’s unified experience and the Cowork interface some accounts still use. Microsoft setup links go directly to Microsoft Learn.
- The [fictional Alder Mill workday](https://github.com/m66se/docketdial/tree/v0.1.0/examples/alder-mill) includes two phone screenshots, a matter register, work records, a prompt, and a separate answer key.
