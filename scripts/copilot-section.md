## Use in Microsoft 365 Copilot Cowork

Use the signed-in timekeeper’s accessible Outlook, calendar, Teams, and work files within the requested scope. When the phone records are in images, inspect the attached images or selected work OneDrive files. If a source or existing docket export cannot be read, finish the supported portion and list the missing source. When the lawyer requests a workbook, use Excel to create a private, editable draft with separate review and evidence sheets. Keep raw source details off any client-facing sheet.
